# SixStarAI 🚀

[![Spring Boot](https://shields.io)](https://spring.io)
[![Vue](https://shields.io)](https://vuejs.org)
[![LangChain](https://shields.io)](https://langchain.com)

SixStarAI 是一个基于 **Vue + SpringBoot** 架构的企业级智能问答与讨论社区。项目在传统 Web 开发的基础上，深度集成了 **LangChain** 框架，通过对接第三方开源知识库服务（AnythingLLM），扩展了私有知识库的检索增强生成（**RAG**）问答能力。
